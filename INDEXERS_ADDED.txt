ARCHITECTURE:
==============

Each indexer implements the TorrentIndexer interface:
- id: unique identifier
- displayName: user-friendly name
- supports(ctx): filter by movie/tv type and requirements
- search(ctx): async search returning TorrentSearchHit[]

Key features:
✅ Pluggable architecture (no monolithic changes needed)
✅ Parallel execution with 25s timeout per indexer
✅ Automatic deduplication by infoHash
✅ Results sorted by seeders (descending)
✅ Mirror/fallback host support for resilience
✅ Shared utilities for HTML parsing, JSON fetching, size parsing

USAGE:

Example API call:

PERFORMANCE NOTES:
==================

- All indexers run in parallel (Promise.allSettled)
- 25-second timeout per indexer (prevents slowdowns)
- Deduplication by infoHash prevents redundant results
- Results merged and sorted by seeders count
- Cloudflare caching enabled (300s TTL) on JSON/HTML fetches

RESILIENCE:
===========

- Multiple mirror hosts per scraper indexer
- Tries next host if first fails
- Individual indexer failures don't crash entire search
- Error tracking per indexer in response payload
