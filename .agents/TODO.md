## 2. Torrent Engine & Protocol Correctness

### 2a. UDP Tracker Connector (`UDPTrackerClient.swift`)
- **Connection ID Caching**: Caching of transaction and connection IDs must be isolated per host/port. If global caches are used, announce packets sent to tracker A will use the connection ID of tracker B and be dropped.
- **Peer ID Formatting**: Ensure peer ID strings generated by the client are exactly 20 bytes long and do not contain characters disallowed by the tracker specification.

### 2b. DHT BEP 5 Compact Encoding Compliance (`DHTCodec.swift`)
- **Compact Nodes Parser**: Double-check that parsing a 26-byte compact node list doesn't cause out-of-bounds index errors if the peer list length is not a multiple of 26.
- **Routing Table Pings**: Implement a task to ping nodes in the routing table every 15 minutes. Stale nodes (no response) must be pruned.
